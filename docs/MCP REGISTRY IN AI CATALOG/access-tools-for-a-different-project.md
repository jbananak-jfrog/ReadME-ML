If you work on multiple teams (e.g., `frontend-app `vs `backend-api)`, you will need to switch contexts to access the specific tools approved for that work.

**To switch your context:**

Run the following command in your terminal:

```Text bash
jf mcp-gateway project-set <NEW_PROJECT_KEY>
```
